# Fixtures, examples and licenses

The default corpus is small, deterministic, original project-authored material under MIT, copyright 2026 USDZ Validation Kit contributors. [LICENSE](../LICENSE) supplies its permission/copyright notice. [Fixture manifest](../Tests/Fixtures/manifest.json) records stable IDs, purpose, author/source, license/text, obligations, SHA-256, recipe and history for every committed fixture and generator. Tool-generated material must retain generator/version/arguments and the original source license. Tests download no assets.

[valid-usda.usdz](../Tests/Fixtures/valid-usda.usdz) is a 469-byte stored/aligned archive generated independently from [root.usda](../Tests/Fixtures/Sources/root.usda) and [pixel.png](../Tests/Fixtures/Sources/pixel.png), an original complete 1×1 PNG. It supports the [complete native example commands](cli.md#complete-native-examples), which use no external tool. Its manifest includes the reproducible Swift recipe and hash. It contains a Scope and an asset reference, with no visible geometry; an empty preview is expected. It establishes the declared native checks, not full USD/rendering validity.

Test-only archive/image/mutation/resource recipes create temporary malformed, unsupported and boundary cases without extraction or giant committed assets. Header-only PNG/JPEG vectors test bounded header behavior; synthetic `PXR-USDC` bytes test recognition/limitations and are never valid-scene oracles. The fixed adversarial corpus is reproducible with `sh Scripts/test-adversarial.sh`. Resource reproduction and host observations are in [resource results](verification/resource-results.md).

[USDC inventory](../Tests/Fixtures/USDC/inventory.json) preserves 23 original crates and 16 authored USDA sources: nine Apple-written 0.8.0 baseline cases with 41 expected occurrences, and seven cases written separately by Apple and OpenUSD with 30 more occurrences. The fourteen newer files naturally contain exact versions 0.9.0 (live TimeCode, tag 56) or 0.10.0 (live PathExpression, tag 57). No positive fixture was made by changing its version header. Duplicate references, one empty asset literal, inactive prims, unselected variants, all six reference/payload list-op buckets, reference customData, nested dictionaries, arrays, time samples and authored asset expressions retain their authored expectations. Scene PathExpression values are not file references. Asset-expression text retains its backticks and variable name; it is never replaced with the variable's evaluated value.

The inventory's expected values come verbatim from the original authored definitions, independently of the product reader. Logical sites were transcribed from the source and checked against the separately executed Sdf oracle where its APIs expose those sites. `pathElements`, field names and typed container coordinates describe semantic test locations; they are not product output identities or physical byte offsets. The `wrapped` coordinate identifies the typed unregistered Value wrapper, not an authored dictionary key. The raw unregistered value `raw-unregistered.png` is recorded separately, contributes no parsed occurrence, and leaves inspection incomplete. An empty parsed inventory does not establish complete coverage.

[Preserved provenance](../Tests/Fixtures/USDC/evidence/provenance.json) records verified original file/record hashes, source license, writer versions and the upstream wheel pin. Every copied source and crate was checked against its original recorded SHA-256. Apple USD Tools `0.25.11` and `usd-core==26.11` exported the original sources without stage composition or flattening; their outputs and hashes remain distinct. Historical argv in the inventory uses `$RESEARCH_ROOT` in place of the original absolute research directory, preserving argument order. Those records describe the original execution, not a portable command requiring a distributed writer. The OpenUSD export used an anonymous Sdf layer, `ImportFromString`, and `Export`; its wheel is independently packaged and is not a build of the pinned source commit. Neither writer executable nor the wheel is distributed or required by native tests. The original sources, outputs and project-authored evidence are MIT; this does not relicense the external tools, whose own implementation and notices are not copied here.

[Independent oracle evidence](../Tests/Fixtures/USDC/evidence/independent-oracle.json) retains the 23 fixture results and explicit limitations. `ListInfoKeys` omits `arbitraryMetadata` in both unregistered cases, missing the nested `wrapped.png` occurrence. The small [typed-wrapper export](../Tests/Fixtures/USDC/evidence/unregistered.export.usda) and [raw-wrapper export](../Tests/Fixtures/USDC/evidence/unregistered-raw.export.usda) preserve that textual evidence. `GetInfo("subLayerOffsets")` raises a converter `TypeError` on the baseline sublayer case; the sublayer path remains independently compared. Zero-versus-zero agreement on the raw case cannot certify completeness. The writers and oracle share OpenUSD lineage; separate execution and independently authored expectations do not make them independent format implementations. [Historical live-type observations](../Tests/Fixtures/USDC/evidence/live-type-observations.json) preserve the experiment's actual tag/flag evidence separately and supply no expected asset values or semantic sites.

`USDCFixtures.cases()` loads only committed bytes and expectations. `USDCMutationRecipe` provides bounded byte patches and a literal-only LZ4 block encoder for synthetic hostile-input recipes. Its TfFastCompression frame uses a one-byte chunk count (zero for a single block) and four-byte signed little-endian lengths for multiple chunks, following pinned OpenUSD source compatibility rather than the conflicting published eight-byte framing. These synthetic bytes do not establish natural multi-gigabyte writer compatibility. Archive construction stays in `ArchiveRecipe`. Run `swift test --filter 'USDCFixtureTests|FixtureTests'` offline; no Python, installed USD tool, oracle environment, download or product decoder is needed.

Four supplementary genuine originals retain explicit/deleted/ordered list buckets, legacy payload, clip-template and unrelated-string cases in [their provenance](../Tests/Fixtures/USDC/extra/provenance.json). They add one occurrence to the canonical 71 for the 27-input containment run. The tag 52 relative Value wrapper has pinned-source plus independent synthetic evidence only; no writer-produced tag 52 occurs in those originals. PATHS tests protect numeric topology/provenance rather than full scene-path semantics.

The two preserved experiment reports, [bounded feasibility](deliverables/experiments/2026-10-24-usdc-bounded-feasibility-experiment.md) and [0.9/0.10 extension](deliverables/experiments/2026-10-24-usdc-09-010-feasibility-experiment.md), remain historical, conditional research evidence. Their Python reader, oracle, host LZ4 and optional Apple corpus are not shipped prerequisites or substitutes for the native Swift acceptance in [v0.2 verification](verification/usdc-v0-2.md). Original conclusions are unchanged.

[Schema/example manifest](../Tests/Schemas/manifest.json) pins examples, independent goldens, tooling, schemas and third-party dependency artifacts. [Tools/README.md](../Tools/README.md) retains independent literal golden recipes and hash-locked schema-tool setup. Example JSON/SARIF documents describe the complete committed USDA fixture; goldens also retain incomplete, operational and external states. The example verifier only compares bytes; it never regenerates expectations. Review an intentional mismatch against the contract and independent sources before updating bytes/hashes.

The CLI resolves Swift Argument Parser 1.5.0 at revision `41982a3656a71c768319979febd796c6fd111d5c` under Apache-2.0 with Swift Runtime Library Exception. The library has no third-party package dependency but privately compiles vendored LZ4 1.10.0 source under BSD-2-Clause. [Its manifest](../Sources/CUSDCCompression/source-manifest.json) records the upstream revision and exact source/header/license hashes; [NOTICE](../NOTICE) retains the license. No host-installed LZ4 is required. Development schema tools use the pinned distributions/licenses recorded in the schema manifest: jsonschema, attrs, jsonschema-specifications, referencing and rpds-py (MIT), and typing_extensions (PSF-2.0 for the Python <3.13 marker). The OASIS SARIF schema retains its own complete notice and unchanged bytes. [NOTICE](../NOTICE) preserves these applicable texts; third-party materials are not relabeled MIT.

Do not add proprietary sample models or presume gallery assets can be redistributed. Third-party assets require a compatible redistribution grant and all attribution/notices. Product validation neither downloads assets nor offers fixture generation as a public product feature.

[Local Apple asset verification](verification/apple-assets.md) records a separate historical v0.1 opt-in manual corpus of five user-provided downloads, three damaged copies, source hashes and observed results. Those assets, copies and raw reports remain outside version control. They are not required by the normal test suite; no redistribution grant or exact source URL was verified.
